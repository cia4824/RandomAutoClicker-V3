# Random Auto Clicker (Android APK)

## Cach xuat file APK don gian bang GitHub (chi 9 file, khong can Android Studio)

1. Tai va giai nen thu muc du an nay.
2. Tao Repo moi tren GitHub -> keo tha toan bo file va thu muc vao (nho kem `.github`) -> bam **Commit changes**.
3. Mo tab **Actions** -> cho **Build Android APK** bao xanh -> tai **RandomAutoClicker-APK** o muc **Artifacts**.
